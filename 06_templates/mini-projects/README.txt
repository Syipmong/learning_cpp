TEMPLATE MINI-PROJECTS
======================

01_FIXED_VECTOR
---------------
Implement a fixed-capacity vector-like type with iterators and bounds checks.

02_GENERIC_CSV
--------------
Create a generic formatter that accepts printable fields and produces rows.
Use concepts to constrain the public API.

03_ALGORITHM_LIBRARY
--------------------
Implement generic filter, map, and reduce operations, then compare them with
standard library algorithms and ranges.
