# 06 - Templates and generic programming

## Goals

Learn function and class templates, type deduction, specialization,
constraints, concepts, compile-time programming, and generic interfaces.

## Exercises

Use the starter files in `exercises/`.

1. Write a generic `maximum` function.
2. Implement a fixed-size `Stack<T, N>`.
3. Add concepts requiring sortable and printable types.
4. Create a compile-time factorial and test it with `static_assert`.
5. Write a generic CSV row formatter.
6. Compare a constrained template with an unconstrained one and explain the
   diagnostics.

Starter files:

- `01_maximum.cpp`
- `02_stack.cpp`
- `03_concepts.cpp`
