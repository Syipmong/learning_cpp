MODERN C++ MINI-PROJECTS
========================

01_CONCURRENT_LOG_PROCESSOR
---------------------------
Use a producer/consumer design to process many files. Define shutdown and
error behavior before writing threads.

02_TASK_SCHEDULER
-----------------
Schedule delayed tasks using jthread or async facilities. Support cancellation
and ensure every worker finishes cleanly.

03_RESOURCE_CACHE
-----------------
Build a cache with clear ownership, eviction behavior, and synchronization.
Measure it against a simple non-cached implementation.
