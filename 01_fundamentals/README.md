# 01 - Fundamentals

For exact commands to build and run each exercise, read
[RUNNING_EXERCISES.txt](C:/dumps/learning_cpp/RUNNING_EXERCISES.txt) first.

## Goals

Learn program structure, variables, arithmetic, input/output, conditions,
loops, functions, scope, and basic problem solving.

## Order

1. `examples/01_hello.cpp` - compilation and output
2. `examples/02_control_flow.cpp` - conditions and loops
3. `examples/03_functions.cpp` - parameters and return values
4. Complete the exercises in order.

## Exercises

Open the matching starter file in `exercises/`, implement the TODOs, and run
it after every meaningful change. Do not edit the examples to solve exercises.

1. Read a name and print a greeting.
2. Convert Celsius to Fahrenheit and Kelvin.
3. Print a multiplication table for a chosen number.
4. Find the largest of three numbers without using `std::max`.
5. Build a number-guessing game with a limited number of attempts.
6. Write functions for factorial, prime checking, and greatest common divisor.
7. Print the first `n` Fibonacci numbers.
8. Build a menu-driven calculator with input validation.

Starter files:

- `01_greeting.cpp`
- `02_temperature.cpp`
- `03_number_game.cpp`
- `04_functions.cpp`

## Completion test

Explain the difference between a declaration and a definition, pass a value
to a function, and trace a loop without running it.
