FUNDAMENTALS MINI-PROJECTS
==========================

01_CALCULATOR
-------------
Build a command-line calculator supporting +, -, *, and /. Validate input
and division by zero. Separate each operation into a function.

02_QUIZ
-------
Ask ten multiple-choice questions, track the score, reject invalid choices,
and display a final percentage.

03_NUMBER_ANALYZER
------------------
Read numbers until the user quits. Report count, sum, minimum, maximum, and
average. Handle the case where no numbers were entered.

Each project must include a README, source file, sample run, and a note about
what you would improve next.
