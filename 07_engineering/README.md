# 07 - Professional C++ engineering

## Goals

Learn testing, sanitizers, static analysis, formatting, CMake targets,
libraries, API design, logging, error handling, profiling, and architecture.

## Practice tasks

The text specifications in `exercises/` are intended to become complete
projects. Create source and test files as you implement each specification.

1. Add unit tests for the exercises using a test framework of your choice.
2. Build with AddressSanitizer and UndefinedBehaviorSanitizer where supported.
3. Enable compiler warnings as errors for a small project.
4. Split one program into a library, executable, and tests.
5. Profile a slow algorithm, form a hypothesis, optimize, and measure again.
6. Write a short design document explaining ownership, errors, and complexity.

## Quality gate

Before calling a project complete: it builds from a clean directory, tests
pass, warnings are understood, formatting is consistent, and the README
explains how to use it.
