# 00 - Setup and workflow

## Checklist

1. Install a C++20 compiler and CMake.
2. Confirm `cmake --version` and your compiler version.
3. Configure and build from the repository root.
4. Set a breakpoint in one example and step through it.
5. Learn to read compiler warnings; never ignore them by default.

## Daily routine

Use this loop: learn one concept, write a tiny program, test an edge case,
debug one failure, and record what you learned in your own notes.

## Suggested Git workflow

Create one commit per completed lesson. Use messages such as
`Complete variables lesson`. Do not commit generated `build` files.
