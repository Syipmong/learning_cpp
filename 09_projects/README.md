# 09 - Capstone projects

Choose projects in increasing difficulty. Each project should have its own
`README.md`, source directory, tests, sample data, and CMake target.

## Beginner

- **CLI quiz**: questions, scoring, file persistence, input validation.
- **Unit converter**: commands, units, validation, and clean functions.

## Intermediate

- **Task manager**: CRUD commands, JSON or text persistence, sorting, tests.
- **Inventory system**: products, transactions, reports, and file storage.
- **Text search tool**: recursively scan files, rank matches, and report errors.

## Advanced

- **HTTP client**: networking library, timeouts, retries, and tests.
- **Concurrent log processor**: producer/consumer pipeline and benchmarks.
- **Game engine slice**: entity/component design, timing, input, and rendering.

## Expert portfolio standard

Document requirements, architecture, API contracts, ownership, complexity,
testing strategy, benchmarks, known limitations, and future improvements.
