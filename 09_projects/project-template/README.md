# Project template

Copy this folder for each capstone.

## Definition of done

- The project builds from a clean CMake directory.
- The main use cases have automated tests.
- Invalid input produces a useful error.
- Ownership and thread-safety assumptions are documented.
- At least one benchmark or measured performance claim is included.
- The README contains build, run, test, and example commands.

Suggested folders: `include/`, `src/`, `tests/`, `data/`, and `docs/`.
