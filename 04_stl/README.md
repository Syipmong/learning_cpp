# 04 - STL, algorithms, and ranges

## Goals

Use containers, iterators, algorithms, lambdas, function objects, associative
containers, custom comparisons, and ranges. Learn complexity and choose the
right data structure.

## Exercises

Use the starter files in `exercises/`.

1. Sort students by grade, then name.
2. Build a word-frequency counter using `std::unordered_map`.
3. Implement a phone book with `std::map`.
4. Use `std::transform`, `std::remove_if`, and `std::accumulate`.
5. Reimplement a pipeline with C++20 ranges.
6. Compare lookup behavior of vector, map, and unordered_map on generated data.

Starter files:

- `01_student_sort.cpp`
- `02_word_frequency.cpp`
- `03_ranges_pipeline.cpp`
