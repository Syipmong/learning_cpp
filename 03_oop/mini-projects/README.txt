OOP MINI-PROJECTS
=================

01_BANK_SYSTEM
--------------
Implement accounts, deposits, withdrawals, transfers, and transaction history.
Use class invariants and exceptions for rejected operations.

02_LIBRARY
----------
Model books, members, loans, returns, and overdue reports. Prefer composition
and use polymorphism only where behavior genuinely varies.

03_INVENTORY
------------
Model products and stock movements. Prevent negative inventory and produce a
restock report.
