CORE MINI-PROJECTS
==================

01_CONTACT_MANAGER
------------------
Expand the contact exercise with file loading, saving, search, update, and
delete commands. Decide how malformed records are reported.

02_FILE_STATISTICS
------------------
Read a path from the command line and report lines, words, characters, and
the ten most common words.

03_EXPENSE_TRACKER
-----------------
Store dated expenses, calculate totals by category, and save data safely.

Use structs first. Refactor to classes only when an invariant needs protection.
